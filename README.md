# Mirik

Простой приватный чат на Flask и SQLite.

## Что улучшено

- безопасная конфигурация `SECRET_KEY` через переменную окружения;
- CSRF-защита всех POST-форм;
- безопасные cookie для сессий;
- базовые security headers;
- проверка доступа к чатам перед чтением и отправкой сообщений;
- ограничение длины сообщений и названий комнат;
- более надёжная генерация кодов приватных комнат;
- загрузка только последних 100 сообщений комнаты;
- индексы для частых запросов базы данных;
- современный адаптивный интерфейс для ПК и телефона;
- `requirements.txt` для установки зависимостей;
- `.gitignore` для секретов, локальных БД и Python-кэша.

## Запуск

```bash
python -m venv .venv
# Windows:
.venv\\Scripts\\activate

pip install -r requirements.txt
```

Перед запуском в production задай длинный случайный `SECRET_KEY`.

```bash
# Windows PowerShell
$env:SECRET_KEY = "your-long-random-secret"
python app.py
```

Открой `http://127.0.0.1:5000`.

## Важно

Файлы SQLite и секреты не должны храниться в Git. Для production лучше использовать PostgreSQL или другую серверную БД и отдельный production WSGI-сервер.
